# Day 8 — Lab 8: Workplace Writing II — Summary Fidelity and Report Scaffolding

## 📌 Overview

This lab focuses on using **Generative AI for accurate summarisation and management-report preparation in aviation**.

The main focus is **summary fidelity** — preserving the meaning, important figures, limitations, and factual information from an original source without adding unsupported claims. The lab also introduces **report scaffolding**, verification placeholders, numerical checking, and human review before an AI-generated management report is used.

---

## 🎯 Objectives

* Understand summary fidelity.
* Create accurate AI-generated summaries.
* Preserve important numerical information.
* Identify omissions, distortions and inventions.
* Separate verified facts from unsupported conclusions.
* Build structured management reports.
* Use `[VERIFY]` placeholders for unavailable information.
* Review AI-generated reports before use.
* Apply human verification to AI-generated business content.

---

## 📊 Airport Passenger-Service Report

The first activity uses an airport passenger-service report covering **120 passenger comments** during August.

The comments included:

| Category                             | Comments |
| ------------------------------------ | -------: |
| Long security queues                 |       45 |
| Unclear directional signs            |       30 |
| Baggage delays                       |       20 |
| Limited seating near departure gates |       15 |
| Staff helpfulness                    |       10 |
| **Total**                            |  **120** |

Airport management also introduced **two temporary information desks near security for a two-week trial**. The effect of this trial had not been measured when the source report was prepared.

---

## ✍️ Summary Fidelity

**Summary fidelity** means preserving the meaning and important information of the original source while making it shorter.

A faithful summary should:

* Preserve important facts.
* Preserve important figures.
* Maintain the original meaning.
* Include relevant source limitations.
* Avoid invented information.
* Avoid unsupported recommendations or conclusions.

---

## 🤖 AI Summary Activity

The AI was instructed to summarise the passenger-service report in no more than 100 words while:

* Retaining important figures.
* Distinguishing complaints from positive feedback.
* Avoiding recommendations.
* Avoiding financial information not present in the source.
* Avoiding comparisons with other airports.
* Avoiding unsupported conclusions.

The generated summary was **77 words** and retained the major facts and limitations from the source.

## 🔍 Claim-by-Claim Fidelity Check

## ⚠️ Omissions and Inventions

The lab checks whether an AI summary:

### Omits information

Information from the source is accidentally left out.

### Distorts information

The original meaning or figures are changed.

### Invents information

The AI adds information that does not exist in the source.

In this activity, no material omissions, distortions or inventions were identified.

## 📑 Management Report Scaffold

The lab develops a structured management-report format containing:

1. **Title**
2. **Executive Summary**
3. **Purpose of the Report**
4. **Source and Scope**
5. **Key Findings**
6. **Complaint Categories**
7. **Positive Feedback**
8. **Actions Already Taken**
9. **Limitations**
10. **Recommendations**
11. **Information Requiring Verification**
12. **Conclusion**

The scaffold separates report structure from factual content so that unsupported information is not presented as verified fact.

---

## 🔎 Verification Placeholders

The lab uses `[VERIFY]` placeholders when information is unavailable or requires confirmation.

Examples include:

```text
[VERIFY — CONFIRM SOURCE DATE AND REPORT VERSION]

[VERIFY — MANAGEMENT INPUT REQUIRED]

[VERIFY WITH FINANCE DEPARTMENT]

[VERIFY AFTER TRIAL EVALUATION]

[VERIFY WITH PREVIOUS REPORT]

[VERIFY WITH OPERATIONS]
```

These placeholders prevent AI from filling information gaps with invented facts.

---

## 🧩 Structure vs Facts

The lab distinguishes between report structure and factual information.

| Item                                  | Classification                     |
| ------------------------------------- | ---------------------------------- |
| Report reviewed 120 comments          | Verified source fact               |
| Executive Summary                     | Report structure                   |
| Passenger satisfaction has declined   | Interpretation requiring evidence  |
| Install more directional signs        | Recommendation                     |
| Two information desks were introduced | Verified source fact               |
| The trial was successful              | Information requiring verification |
| Financial Impact                      | Report structure                   |
| [VERIFY]                              | Verification requirement           |

This distinction helps prevent assumptions or proposed actions from being presented as established facts.

---

## 🧠 Key Learnings

* **Summary fidelity** means preserving the meaning and important information of the original source.
* Numerical information should be checked separately.
* Source limitations should remain visible in summaries.
* Omissions and inventions are different types of summary errors.
* Report scaffolding provides an organised structure for management reports.
* Report structure should be separated from factual content.
* `[VERIFY]` placeholders identify information that needs confirmation.
* A concise summary can still be misleading if it removes important limitations or changes figures.
* AI-generated management reports require human review before use.
